# finance-tool

A personal, non-commercial website that helps me and a few friends and family
make saving and investing decisions in Israel.

**How to work here is in `guidelines/`.** Before any work, read
`guidelines/README.md`, then the file for the kind of task you are about to
do: running a task, working with me, research, a page, an interface piece, a
chart, or wording.

Where a doc, report or note disagrees with the guidelines, the guidelines
win and the other text is corrected. My newer words win over both.

**Always, whatever the task** (details in the guidelines):
- Never fill in a tax or financial rule from memory: use the il-finance rule
  base, and if a rule is missing, say so and stop.
- Every number on the site traces to a dated source in `data/`, a calculation
  in `docs/method.md`, or what the person entered.
- Cite official texts, never copies. Unofficial sources are leads only.
- The repository and the site are public: nothing private goes into them.
- `npm run check` passes before anything goes live. Push to `main`; never open
  a pull request.
