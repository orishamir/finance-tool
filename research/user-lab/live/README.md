# Live flags

Every problem the founder flags on the live site from 2026-11-06 on, kept the moment he flags it and before anything is
fixed (`learning-loop.md`). Each folder holds the screen he saw (`screen.png`, his own screenshot where he sent one)
and `case.json`: his words, the page, the device, the commit that was live, the key the grader reads, and the result
of running the reviewer on it before he was asked anything more. These cases were never used to tune the reviewer
until scored; they count toward the live miss rate in `metric.md`.
