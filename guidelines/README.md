# Guidelines

How to do each kind of task on this project. Every agent follows them.

| Before you... | Read |
|---|---|
| start any work | [project.md](project.md): what the site is, its constraints, where things are |
| plan, brief, check or land work | [working.md](working.md) |
| ask the founder something or report to him | [working-with-the-founder.md](working-with-the-founder.md) |
| research a rule or collect prices | [research.md](research.md) |
| build an interface piece, or change a page the founder asked for | [design.md](design.md) |
| make a chart | [charts.md](charts.md) |
| write a sentence, on the site or to the founder | [wording.md](wording.md) |

## How these files work

- **They are binding.** Every agent follows them. Where another doc, a report
  or a note disagrees with them, they win and the other text is corrected.
- **They are principles, not a checklist.** When a step doesn't fit the
  case, use judgement and say why.
- **The founder reviews every file and every change to one.** Each file's
  first lines say whether he has reviewed it yet. Propose changes to him; a
  line that keeps getting in the way is raised with him, not worked around.
- **They are the only place for the founder's preferences.** Agents keep no
  notes about him elsewhere. When he says something new about how he wants
  things, it is proposed here, in the file it belongs to.
- **Nothing private.** The repository is public.
